## Data quality findings

| # | Finding | Status |
|---|---|---|
| Q1 | SESNSP long file = only the 56,312 non-zero month cells of 79,772 wide rows (zero months dropped) | VERIFIED (sums unaffected; monthly means would be biased) |
| Q2 | ITER read as latin-1 → 20/72 municipality names garbled until v2 | VERIFIED |
| Q3 | Name joins lose 205/1,472 detentions (e.g. San Luis Río Colorado, Puerto Peñasco, Bácum) and 17/35 ITAMA cases ("Obregon" ≠ Cajeme; Puerto Peñasco) | VERIFIED |
| Q4 | `fillna(0)` makes unmatched municipalities look crime-free in `total_delitos_sonora` | VERIFIED |
| Q5 | Detentions and ITAMA are a **single quarter** (Q1 2026); SESNSP is 2020–2025; Census is 2020 – mixed reference periods | VERIFIED |
| Q6 | ACLED weekly aggregates are state-level (ADMIN1) – not municipal | VERIFIED |
| Q7 | Google Trends values are relative (0–100 per query block), low volume for several terms in Sonora (14 terms discarded for >50–75 % zeros) | VERIFIED |
